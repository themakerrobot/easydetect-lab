# 수업에서 쓰기 — 선생님용 안내

학생들이 노트북으로 사진에 상자를 그리고(라벨링), 그 사진으로 작은 물체 검출
모델을 학습한 뒤, 그 모델을 Pibo 로봇에 넣어 돌려 보는 수업을 위한 안내입니다.
인터넷과 NVIDIA 그래픽카드 없이 됩니다.

## 필요한 것

- **Windows 10 / 11 64비트** 노트북. 그래픽카드는 필요 없어요(CPU로 학습).
- **메모리 8 GB 이상**. 4 GB에서는 학습이 멈추거나 매우 느릴 수 있어요.
- **디스크 여유 3 GB 이상**: zip을 푼 폴더가 1.5~2 GB쯤이고(추정, 정확한 크기는
  배포 zip을 만든 GitHub Actions 기록의 "Offline bundle size"에 나와요), 학습
  결과가 한 번에 100 MB 안팎씩 쌓여요.
- 브라우저: Chrome 또는 Edge.
- 인터넷: **필요 없어요.** zip을 받을 때만 필요해요(USB로 나눠 줘도 돼요).

## 오프라인 zip 쓰는 법

1. [Releases](https://github.com/themakerrobot/easydetect-lab/releases)에서
   `easydetect-lab-offline-win64.zip`을 받아요. 한 번 받아서 USB 메모리로
   학생 PC에 복사해도 돼요. 인텔 GPU가 있는 노트북(Core Ultra, Arc 그래픽)이면
   `easydetect-lab-offline-win64-intel-gpu.zip`을 받으세요. 학습이 GPU에서 돌아
   더 빠르고, 화면 위쪽에 *인텔 GPU …* 라고 나와요. GPU 드라이버는 최신이어야 해요.
2. (권장) zip 파일을 오른쪽 클릭 → **속성** → 아래쪽 **차단 해제** 체크 → 확인.
   인터넷에서 받은 파일이라는 표시가 풀린 파일마다 붙어서, 실행할 때 경고가 뜨는
   것을 막아 줘요.
3. zip을 **전부 압축 풀기** 해요. 짧은 영문 경로가 가장 안전해요: 예
   `C:\easydetect-lab\`. (zip 안에서 바로 실행하면 안 돼요.)
4. 풀린 폴더의 **`start-lab-offline.bat`** 을 더블클릭해요. 검은 창이 뜨고,
   잠시 뒤 브라우저에 lab이 열려요(`http://127.0.0.1:8080`). 처음에는 1~2분
   걸릴 수 있어요. "Windows의 PC 보호" 창이 뜨면 *추가 정보 → 실행*.
5. 검은 창을 닫으면 lab이 꺼져요. 학생이 만든 데이터셋과 모델은 같은 폴더의
   `data\` 안에 남아서, 다음 시간에 다시 켜면 그대로 있어요.

lab은 GPU가 없으면 학습 화면의 목표를 **수업용 (CPU)** 로 골라 둬요:
ed-n 모델, 입력 320px, 배치 8, 백본 고정, 쿼리 100 · 디노이징 쿼리 30,
에폭은 데이터 크기에 맞춰 자동(300장이면 35에폭, 100장이면 100에폭), 25에폭 동안
나아지지 않으면 멈춤. 바꿀 필요 없이 *학습 시작*만 누르면 돼요.

사진이 적을수록 에폭을 늘리는 이유: 적은 사진은 여러 번 봐야 잘 배워요. 사진
92~143장 데이터에서 100에폭이 30에폭보다 점수가 0.12~0.19 높았어요(세 번씩 학습한
평균). 한 에폭이 짧아서 전체 시간은 300장일 때와 비슷해요.

zip 안에는 Python, PyTorch(CPU), easydetect, lab, 그리고 학습이 시작하는 COCO
사전학습 가중치(ed-n, ed-s)와 COCO 자동 라벨용 모델이 들어 있어서
인터넷을 전혀 쓰지 않아요. (윤곽 칠하기·키포인트용 모델은 기본 zip에 없어요.
그 기능은 인터넷이 될 때 처음 한 번 받아요.)

## 시간은 얼마나 걸리나

| | 시간 | 근거 |
| --- | --- | --- |
| 사진 300장, 수업용, 4코어 CPU A | 에폭당 약 19초 → 35에폭 약 11분 | 측정: 배치 8 한 스텝 0.52초(초당 약 15장). 전체 시간은 계산 |
| 사진 300장, 수업용, 4코어 CPU B (Linux 서버) | 에폭당 25.5초 → 35에폭 약 15분 | 측정: 3에폭(240장 학습 + 60장 검증). 35에폭은 계산 |
| 같은 조건, 쿼리를 줄이지 않으면 | 약 1.9배 느림 | 측정 (CPU B, 사진 48장) |
| 학생 Windows 노트북 | 아직 모름 | **측정 안 함.** 저사양 노트북은 더 걸릴 수 있어요 |
| 사진 100장, 수업용 (100에폭) | 300장 35에폭과 비슷 | 계산: 한 에폭 10스텝 × 100 ≈ 30스텝 × 35 |
| Pibo(라즈베리파이 4B)에서 사진 한 장 | 약 0.16초 | 측정: 수업용 모델(320px, 쿼리 100), openpibo에서 ONNX Runtime |

학습 화면의 진행 막대가 남은 시간을 알려 줘요. 수업 시간이 빠듯하면 에폭을
줄여요(사진이 적으면 50 정도까지는 괜찮아요). 끝난 학습은 *이어서 학습*으로 나중에 더 돌릴 수 있어요.

## 라벨링 요령 (사진 300장 이하)

- **COCO에 있는 물체는 유리해요.** 사과, 바나나, 컵, 병, 책, 의자, 사람, 고양이, 강아지
  같은 80가지는 모델이 이미 알아서, 클래스 이름을 그대로(한국어도 돼요: 사과, 컵)
  붙이면 그 지식에서 시작해요. 사진 몇십 장으로도 잘 배워요.
- **클래스는 2~4개**로 시작해요. 클래스마다 사진 50장 이상, 상자 100개
  이상이면 쓸 만해지기 시작해요. 20장 남짓이면 "되는 것 같다" 정도예요.
- **Pibo의 카메라가 볼 장면**으로 찍어요: 같은 높이, 같은 교실 조명, 같은 거리.
  인터넷 사진보다 로봇 눈높이 사진 50장이 더 도움이 돼요.
- 물체가 **보이는 만큼 꼭 맞게** 상자를 그리고, 사진 속 그 클래스는 **하나도
  빼먹지 말고** 다 그려요. 빠진 상자는 "이건 물체가 아니다"라고 가르치는 셈이에요.
- 배경·각도·거리를 섞고, 물체가 없는 사진도 몇 장(10% 정도) 넣어요.
  빈 사진은 상자 없이 저장하면 돼요.
- 너무 작은 물체(사진의 2% 미만)는 320px 입력에서는 잘 안 잡혀요. 가까이서 찍어요.
- 한 사람이 다 그리기보다 모둠이 나눠 그리고, *통계 보기*에서 클래스별 개수와
  "라벨 없음"을 확인해요.
- 30~50장을 먼저 그려 한 번 학습하고, *전체 자동 라벨*로 나머지의 초안을 만든 뒤
  고치면 훨씬 빨라요. 컵·사과·사람처럼 COCO가 아는 물체는 학습 전에도 자동 라벨이
  돼요(클래스 이름이 `컵`이면 COCO의 cup으로 그려요). 아무것도 못 찾은 사진은
  빈 라벨로 저장하지 않고 그대로 둬요 — 직접 확인해서 그려 주세요.
- 클래스 이름은 한글도 돼요. 다만 Pibo의 화면에 그릴 때는 번호(#0, #1…)로
  보여요(OpenCV가 한글을 못 그려요). 영어 이름이면 그대로 보여요.

## 모델을 Pibo로 옮기기

1. 학습이 끝난 작업을 열고 **다운로드 → ONNX 파일 하나** 를 눌러요.
   `job<번호>.onnx` 파일 **하나**가 받아져요(몇 초 걸려요). 클래스 이름과
   이 모델의 **확신 기준**이 파일 안에 들어 있어요. 확신 기준은 검증 사진에서
   놓치는 것과 잘못 찾는 것이 함께 가장 적었던 점수(0.25~0.70)예요.
2. 파일을 Pibo로 복사해요(USB 메모리, 또는 같은 와이파이라면
   `scp job3.onnx pi@<Pibo IP>:~/`).
3. Pibo의 사물 인식 설정에서 이 파일을 모델로 고르면, 기본 COCO 모델 대신 이
   모델로 인식해요.

로봇 코드 없이 파일만 시험해 보려면, lab 폴더의 `pibo/detect.py`를 같은 곳에
복사하고 Pibo에서 이렇게 해요.

```
python3 detect.py 사진.jpg --model job3.onnx   # 찾은 것을 글로 보여 줘요
python3 detect.py 0 --model job3.onnx          # 카메라 0번으로 계속, Ctrl+C로 멈춤
```

`detect.py`는 numpy, OpenCV, onnxruntime만 써요(easydetect·torch 불필요). lab의
추론 화면과 같은 계산이라 같은 사진이면 같은 상자와 점수가 나와요(자동 테스트로
확인). onnxruntime은 **1.13 이상**이어야 해요(모델이 opset 17).
`python3 -c "import onnxruntime; print(onnxruntime.__version__)"`로 확인하고,
낮으면 `pip3 install -U onnxruntime`. **64비트 OS**(`uname -m`이 `aarch64`)여야
pip로 onnxruntime이 깔려요.

## 문제가 생기면

**bat 실행이 막혀요 (윈도우가 차단)**
인터넷에서 받은 파일이라 윈도우가 막는 거예요.
1. 파란 "Windows의 PC 보호" 창 → *추가 정보* → *실행*.
2. 실행 버튼이 없거나 도중에 python.exe가 막히면, 압축을 풀기 전의 zip을 오른쪽 클릭 →
   *속성* → *차단 해제* 체크 → 확인. 풀어 둔 폴더는 지우고 다시 풀어요.
   이미 풀었다면 PowerShell에서 한 번에 풀 수 있어요 (경로는 바꿔서):
   ```powershell
   Get-ChildItem -Recurse "C:\Users\<이름>\Desktop\easydetect-lab-offline" | Unblock-File
   ```
3. "시스템 관리자가 이 앱을 차단했습니다"면 학교 PC 정책이에요. 관리자 권한이 있는
   분이 허용해야 해요 (수업 전에 한 대로 미리 확인해 두세요).

- 창에 "python 폴더나 lab 폴더가 없어요": zip 안에서 실행했어요. 전부 압축을
  푼 뒤 다시 실행해요.
- 브라우저가 안 열려요: 직접 `http://127.0.0.1:8080`을 열어요.
- "8080 포트" 관련 오류: 다른 프로그램이 쓰고 있어요.
  명령 프롬프트에서 `start-lab-offline.bat --port 8090`.
- 학습이 너무 느려요: 다른 프로그램을 닫고, 노트북을 전원에 연결하고(배터리
  절약 모드는 CPU를 느리게 해요), 에폭을 줄여요.
- 한글 이름 폴더(`C:\Users\홍길동\Downloads\...`)에서 문제가 생기면
  `C:\easydetect-lab\`처럼 영문 경로로 옮겨요.
